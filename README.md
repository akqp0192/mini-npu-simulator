# Mini NPU Simulator

## 실행 방법
`main.py`, `data.json`, `README.md`를 같은 폴더에 둔 뒤 터미널에서 `python main.py`를 실행합니다.

- `1`: 3x3 사용자 입력 모드
- `2`: data.json 분석 모드
- `0`: 종료

## 구현 요약
- 라벨 정규화: `+`, `cross`는 `Cross`; `x`는 `X`로 표준화합니다.
- MAC: 중첩 for문으로 같은 위치의 값을 곱하고 누적합니다.
- 동점: `abs(score_cross - score_x) < 1e-9`이면 `UNDECIDED`입니다.
- JSON: 패턴 키, 필수 항목, 라벨, 행렬 크기와 숫자 형식을 검증합니다.

## 시간 복잡도
N x N 행렬의 MAC 연산은 N²회의 곱셈 및 누적을 수행하므로 시간 복잡도는 O(N²)입니다. 추가 공간 사용량은 누적 점수 변수뿐이므로 O(1)입니다.

## 성능 측정
3x3, 5x5, 13x13, 25x25 행렬을 크기별 10회 측정하고 평균 시간을 ms로 출력합니다.
