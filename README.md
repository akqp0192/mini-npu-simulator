# Mini NPU Simulator

## 1. 프로젝트 소개

본 프로젝트는 Python을 이용하여 간단한 NPU(Neural Processing Unit)의 MAC 연산과 패턴 분류 과정을 시뮬레이션하는 프로그램입니다.

입력된 패턴과 Cross 및 X 필터의 MAC 연산 결과를 비교하여 패턴을 판정하며, JSON 데이터를 이용한 자동 분석과 성능 측정 기능을 제공합니다.

## 2. 실행 방법

### 개발 환경
- Language: Python
- IDE: Visual Studio Code
- Library: json, os, re, time, math

### 실행 명령어

```bash
python main.py
```

### 메뉴 구성
- 1. 사용자 입력 (3x3): 필터와 입력 패턴을 직접 입력하여 판정합니다.
- 2. data.json 분석: JSON에 저장된 필터와 패턴을 자동으로 분석합니다.
- 0. 종료: 프로그램을 종료합니다.

## 3. 주요 기능

### 3-1. MAC 연산
중첩 for문을 사용하여 입력 패턴과 필터의 동일한 위치에 있는 값을 곱하고 누적합니다.

### 3-2. 패턴 분류
Cross 필터와 X 필터의 MAC 연산 점수를 비교하여 더 높은 점수를 가진 패턴으로 분류합니다.

- Cross 점수가 높은 경우: Cross
- X 점수가 높은 경우: X
- 두 점수의 차이가 EPSILON(1e-9)보다 작은 경우: UNDECIDED

### 3-3. JSON 데이터 분석
JSON 파일에서 필터와 패턴 데이터를 불러와 행렬 크기, 데이터 형식, 라벨 등을 검증합니다.

각 패턴의 판정 결과를 expected 값과 비교하여 PASS 또는 FAIL을 출력합니다.

## 4. 결과 리포트 및 실패 원인 분석

프로그램은 각 테스트 케이스의 Cross 점수, X 점수, 최종 판정 결과를 출력합니다.

실패가 발생할 수 있는 주요 원인은 다음과 같습니다.

1. **패턴 키 형식 오류**: 패턴 식별자가 `size_N_식별자` 형식과 일치하지 않는 경우
2. **필터 데이터 누락**: JSON에 Cross 또는 X 필터가 없는 경우
3. **행렬 크기 불일치**: 입력 패턴이나 필터의 행 또는 열 개수가 지정된 크기와 다른 경우
4. **잘못된 데이터 형식**: 행렬 원소가 숫자가 아니거나 유효하지 않은 값인 경우
5. **라벨 오류**: expected 값이 `+`, `cross`, `x` 중 하나가 아닌 경우
6. **판정 불일치**: 실제 판정 결과와 expected 값이 다른 경우
7. **동점 발생**: 두 점수의 차이가 EPSILON보다 작아 UNDECIDED로 판정되는 경우

각 테스트에서 발생한 실패 원인을 별도로 기록하고, 마지막에 전체 테스트 수와 PASS 및 FAIL 개수를 요약합니다.

## 5. 시간 복잡도 분석

MAC 연산은 N×N 크기의 행렬을 대상으로 수행됩니다.

- 바깥쪽 반복문: N회 실행
- 안쪽 반복문: N회 실행
- 전체 연산 횟수: N×N = N²

따라서 MAC 연산의 시간 복잡도는 다음과 같습니다.

**시간 복잡도: O(N²)**

추가 공간은 누적 점수를 저장하는 변수만 사용하므로 MAC 함수의 추가 공간 복잡도는 O(1)입니다.

## 6. 성능 측정

행렬 크기별 MAC 연산 성능을 측정합니다.

- 측정 크기: 3×3, 5×5, 13×13, 25×25
- 반복 횟수: 각 크기별 10회
- 측정 도구: `time.perf_counter()`
- 결과 단위: ms
- 측정 방법: 10회 실행 시간의 평균 계산

행렬 크기가 증가할수록 연산 횟수가 N²에 비례하여 증가하는 것을 확인할 수 있습니다.

실제 측정 시간은 CPU 성능과 Python 실행 환경 등에 따라 달라질 수 있습니다.
